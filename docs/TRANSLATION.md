# Локальный перевод EN → RU

Реализация от 17 ноября 2026 года. UI и управление обработкой написаны на C++/Qt; отдельный локальный сервер Ollama выполняет модель перевода. По умолчанию используется `qwen2.5:3b`.

## Поток данных

```text
Локальный видеофайл
  → FFmpeg: PCM-окно до 20 секунд
  → Whisper: английские реплики с таймкодами
  → Ollama на 127.0.0.1:11434: русский текст
  → проверка числа и содержимого реплик
  → публикация русского и английского текста в GUI
  → продвижение готового диапазона и возобновление видео
```

Перевод выполняется внутри существующего рабочего потока ASR после каждого окна. Отдельной неограниченной очереди нет: одновременно обрабатывается одно окно, а прежнее ограничение опережения остаётся в силе. Интерфейс не блокируется ожиданием HTTP. Модель остаётся загруженной в Ollama до 10 минут после запроса.

Реплики переводятся последовательно, по одной на запрос: небольшая модель при пакетном переводе может переносить смысл между элементами даже при верном числе ответов. JSON schema требует ровно один непустой перевод. Таймкоды не генерируются моделью: они копируются из исходной реплики. Контекст соседних реплик пока не передаётся; оборванные границей окна фразы могут переводиться менее точно.

При отмене атомарный флаг прерывает HTTP-запрос; таймаут запроса — 120 секунд. Ответы больше 1 МиБ, некорректный JSON, незавершённая генерация, пустые переводы и неверное число элементов считаются ошибкой. Перенаправления и прокси отключены; допускается только loopback IPv4. Облачные возможности самой Ollama нужно отключить запуском `OLLAMA_NO_CLOUD=1 ollama serve`.

Прежняя проверка поколения задачи защищает и русские результаты. Перевод публикуется перед обновлением конца готового диапазона. Поэтому плеер не возобновляется только потому, что английский текст уже распознан.

## Поведение пользователя

- Перевод включён по умолчанию; переключатель и имя модели находятся в настройках речи.
- «Распознать и перевести» запускает оба этапа. Английский оригинал можно скрыть отдельной галочкой.
- При ручной паузе результаты продолжают готовиться в пределах запаса, но видео само не запускается.
- Перемотка за пределы готового диапазона очищает обе сгенерированные дорожки и перезапускает задачу с новой позиции.
- Импорт перевода SRT во время активного автоперевода останавливает обработку и заменяет дорожку.
- Остановка сохраняет уже полученные реплики. Смена файла очищает их.
- Отсутствие сервера или модели показывается как ошибка с командой для исправления. Автоматического скачивания моделей из UI нет.
- Боковой список и экспорт SRT пока относятся к оригиналу; перевод выводится поверх видео.

## Запуск и проверки

См. настройку Ollama в [README.ru.md](../README.ru.md). После запуска сервера и скачивания модели:

```sh
cmake --build --preset dev --parallel
ctest --preset dev
QREPLI_TEST_TRANSLATION=1 ./build/test_translation realModel
QREPLI_TEST_TRANSLATION=1 \
QREPLI_TEST_MODEL="$PWD/models/ggml-base.en.bin" \
QREPLI_TEST_AUDIO="$PWD/build/speech-demo.mp4" \
./build/test_player realTranslatedPlayback
```

Последний тест требует короткого английского ролика с речью в районе второй секунды. `speech-demo.mp4` — локальный QA-артефакт, не часть репозитория. Для multi-config сборки добавьте каталог конфигурации к путям исполняемых файлов.

Тесты без модели используют локальный тестовый HTTP-сервер: проверяют порядок/таймкоды, неправильные ответы, отсутствие модели, таймаут и отмену. Реальные интеграционные тесты проверяют кириллический результат, ручную паузу, последующее воспроизведение и очистку перевода при смене видео.

Качество перевода зависит от ошибок Whisper, разбиения фиксированных окон и выбранной модели. Точное сохранение числа реплик проверяется программно; смысловая точность и отсутствие галлюцинаций не гарантируются этой проверкой.

## Проверка реализации на macOS ARM64

- Основная сборка: 4/4 набора CTest прошли (`build/translation-tests.log`).
- Debug-сборка переводчика: 13 проверок прошли, включая реальную Ollama (`build/debug-translation.log`). Эта отдельная тестовая сборка создана без Whisper; полный путь Whisper → перевод проверен в RelWithDebInfo.
- Интеграция реального английского аудио с Whisper и Ollama: прошла (`build/translation-player-real.log`). Проверены русский текст в контроллере, сохранение ручной паузы, воспроизведение после подготовки и смена файла.
- В окне тестового экземпляра проверены настройки и появление русских субтитров поверх видео. Пользовательский экземпляр плеера не закрывался.

На тестовой фразе получен результат: «Добро пожаловать в наш видео-плеер, мы можем распознавать английский язык на этом компьютере, субтитры». Небольшая модель 3B иногда переводит неудачно или оставляет английские слова, особенно в коротких и оборванных фрагментах. Проверка структуры ответа не заменяет оценку качества перевода; более крупную локальную модель можно выбрать в настройках при достаточной памяти.
