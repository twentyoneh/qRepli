# Как работает qRepli

Описание текущей реализации на 16 ноября 2026 года. Здесь ASR означает распознавание речи в текст.

Программа воспроизводит локальное видео и параллельно читает его аудиодорожку для Whisper. Полученные английские реплики привязываются ко времени видео и показываются поверх кадра. **Автоматического перевода на русский пока нет**: вторую дорожку можно загрузить из готового SRT. Предлагаемое подключение переводчика вынесено отдельно.

## 1. Кто за что отвечает

| Компонент | Роль |
| --- | --- |
| `main.cpp` | Создаёт приложение, контроллер и QML-интерфейс; обрабатывает параметры запуска. |
| `Main.qml` | Окно, видеоповерхность, кнопки, субтитры, список реплик, настройки. |
| `PlayerController` | Связывает интерфейс, плеер, распознавание и временные шкалы субтитров. |
| `QMediaPlayer` | Воспроизводит файл, сообщает позицию и состояние. |
| `TranscriptionService` | Управляет фоновой задачей Whisper, её отменой и доставкой результатов. |
| `extractAudio()` | Запускает отдельный FFmpeg-процесс для получения короткого PCM-фрагмента. |
| `SubtitleTrack` | Хранит реплики с началом и концом, читает и записывает SRT, ищет текст по времени. |
| `SubtitleModel` | Отдаёт список реплик интерфейсу через `QAbstractListModel`. |

Интерфейс и объекты управления работают в главном потоке Qt. Распознавание и ожидание FFmpeg выполняются в отдельном `QThread`. Сам FFmpeg — отдельный процесс. У медиабэкенда Qt могут быть собственные внутренние потоки.

Видеоплеер и распознавание **независимо читают один файл**. Whisper не перехватывает звук из динамиков: он получает аудио через FFmpeg. Поэтому можно подготовить текст заранее, а громкость плеера не влияет на распознавание.

## 2. Открытие видео

1. Пользователь выбирает или перетаскивает локальный файл.
2. `openMedia()` проверяет, что файл существует и доступен для чтения. Неверный путь не заменяет текущий файл.
3. Контроллер отменяет прежнее распознавание, останавливает воспроизведение, очищает обе дорожки субтитров и список реплик.
4. `QMediaPlayer` получает новый источник и начинает воспроизведение.
5. После загрузки доступны длительность, перемотка и аудиодорожки. Распознавание запускается отдельной кнопкой; параметр `--transcribe` позволяет запросить его при запуске приложения.

Открытие файла само по себе не включает ASR. Воспроизведение без распознавания тоже работает.

## 3. Что происходит после «Распознать»

Контроллер проверяет поддержку Whisper в сборке, наличие загруженного видео с аудиодорожкой, возможность перемотки, путь к модели и исполняемый файл FFmpeg. Ошибка отображается в интерфейсе.

Начало обработки берётся немного раньше текущей позиции:

```text
start = max(0, текущая позиция − 1000 мс)
processedStart = start
processedUntil = start
```

Одна секунда предшествующего аудио помогает начать распознавание после перемотки. Это не перекрытие всех следующих окон.

Старый оригинал очищается, создаётся новая задача. Включённый режим ASR требует готового обработанного интервала для текущей позиции, поэтому воспроизведение ожидает первый результат.

Рабочий поток загружает локальную модель Whisper. Если выбран GPU и загрузить контекст с GPU не получилось, выполняется попытка загрузки на CPU. На этом этапе модель создаётся один раз и используется для всех окон данной задачи. После перезапуска задачи модель загружается заново.

## 4. Обработка аудио окнами

Цикл идёт от стартовой позиции к концу видео:

1. Проверяется отмена и конец файла.
2. Если начало следующего окна дальше чем на 30 секунд от позиции плеера, рабочий поток ждёт, проверяя позицию и отмену каждые 50 мс.
3. FFmpeg извлекает до 20 секунд выбранной аудиодорожки: один канал, 16 000 отсчётов в секунду, `float32`.
4. PCM передаётся через стандартный вывод процесса прямо в память. Временный WAV не создаётся.
5. Проверяется длительность и средняя энергия сигнала — RMS. Если аудио короче 100 мс или RMS не выше `0.0005`, Whisper пропускается. Это простая проверка тишины, а не полноценный детектор речи.
6. Для подходящего аудио Whisper распознаёт **английский** текст. В параметрах стоят `language = "en"`, `translate = false`, `no_context = true`.
7. Времена сегментов переводятся из относительных в абсолютные: к ним добавляется начало окна. Конец ограничивается фактической длиной аудио и границей окна. Пустые, некорректные сегменты и сегменты с вероятностью отсутствия речи `≥ 0.8` отбрасываются.
8. В главный поток отправляется `chunkReady(cues, end)`, затем начинается следующее окно.

Даже если в окне тишина, отправляется пустой список реплик **с концом обработанного интервала**. Иначе плеер ошибочно ждал бы субтитры в месте, где никто не говорит.

Двадцать секунд — длительность входного фрагмента, а не обязательное время ожидания. Файл можно читать быстрее воспроизведения. Реальная задержка зависит от модели, устройства и аудио; первый результат приходит после обработки окна целиком.

Ограничение опережения проверяется перед чтением окна. Например, при позиции `0` можно обработать `0–20` и `20–40` секунд; перед окном `40–60` задача подождёт. Когда позиция достигнет `10` секунд, это окно станет разрешено. Поэтому готовый запас может доходить примерно до 50 секунд.

В памяти нет PCM всего фильма: аудио обрабатывается короткими буферами. Текст уже обработанных реплик текущей задачи накапливается.

## 5. Как текст появляется на экране

Результаты доставляются через очередь событий Qt. В главном потоке контроллер:

1. Добавляет реплики в оригинальную дорожку.
2. Обновляет `processedUntil` концом обработанного окна.
3. Обновляет модель списка реплик.
4. Выбирает субтитры для текущей позиции и проверяет возможность воспроизведения.

Одна реплика содержит `startMs`, `endMs` и `text`. Она активна при:

```text
startMs ≤ позиция видео < endMs
```

На каждом `positionChanged` контроллер ищет активный оригинал и перевод независимо. Перекрывающиеся реплики могут отображаться вместе. Время видео является общей шкалой для обеих дорожек.

Над видео можно показать обе дорожки одновременно. Боковой список сейчас содержит оригинал, а если оригинала нет — загруженный перевод. Это ещё не список пар EN/RU. Нажатие на реплику перематывает видео к её началу.

## 6. Почему у плеера два состояния «играет»

`playRequested` хранит намерение пользователя смотреть, а `playing` отражает фактическое состояние `QMediaPlayer`.

| Условие | Поведение |
| --- | --- |
| Пользователь нажал паузу | `playRequested = false`; готовые результаты не запускают видео. |
| Пользователь хочет смотреть, но текущий интервал ещё не обработан | Временная пауза; `playRequested` остаётся `true`. |
| Интервал готов и пользователь хочет смотреть | Плеер продолжает воспроизведение. |
| Распознавание выключено | Ожидание ASR не ограничивает просмотр. |

Пауза видео не отменяет ASR: задача может заполнить запас впереди текущей позиции и затем ждать. Если распознавание отстаёт, плеер приостанавливается на границе готового диапазона.

## 7. Перемотка и защита от старых результатов

Если новая позиция внутри `[processedStart, processedUntil)`, используются уже полученные реплики. Распознавание не перезапускается.

Если позиция вне диапазона, контроллер отменяет задачу, очищает сгенерированный оригинал и запускает таймер на 250 мс. Следующая перемотка перезапускает таймер. Это позволяет не создавать новую задачу на каждое движение ползунка. По таймеру ASR стартует около окончательно выбранной позиции с отступом в одну секунду назад.

Отмена кооперативная: задача получает атомарный флаг, FFmpeg при отмене прерывается, Whisper проверяет флаг через callback. Поток не обрывается принудительно. Пока он завершает работу, хранится только последний запрос на запуск; две модели одновременно не обрабатывают разные задачи.

Каждая отмена увеличивает номер **поколения задачи**. Сигналы с текстом, ошибками и статусом несут захваченный номер. Перед применением результата в GUI номер сравнивается с текущим. Поэтому поздно пришедший результат прежнего видео или позиции игнорируется.

Сохранённого индекса всего видео пока нет. После перемотки за пределы диапазона текст предыдущей задачи теряется, если его не экспортировали. Загруженный SRT перевода при такой перемотке сохраняется.

## 8. SRT, остановка и ошибки

- **Импорт оригинала:** файл сначала полностью проверяется; успешная загрузка останавливает ASR и заменяет оригинальную дорожку.
- **Импорт перевода:** заменяет только дорожку перевода, ASR продолжает работу.
- **Неверный SRT:** показывает ошибку, уже загруженная дорожка сохраняется.
- **Остановить ASR:** отменяет задачу, оставляет полученный текст и снимает ожидание обработки. Просмотр продолжается, если пользователь не ставил его на паузу.
- **Сменить аудиодорожку:** если ASR был включён, распознавание перезапускается для выбранной дорожки.
- **Изменить модель, FFmpeg или GPU:** распознавание останавливается; настройки сохраняются через `QSettings`.
- **Ошибка FFmpeg или Whisper:** просмотр ставится на паузу, выводится сообщение. Для продолжения распознавания нужно устранить причину и запустить его снова.
- **Экспорт:** записывает имеющуюся оригинальную дорожку в UTF-8 SRT через `QSaveFile`. Экспорт до окончания обработки содержит только уже полученные реплики. Запись поверх открытого видео или модели запрещена.
- **Закрытие программы:** отмена задачи и ожидание завершения рабочего потока, затем остановка плеера.

При работе с локальными моделями приложение не отправляет видео, аудио или текст в сеть. Субтитры хранятся в памяти до экспорта; постоянного кэша распознавания пока нет.

## 9. Как добавить перевод следующим этапом

Четвёртая схема — предложение, **не описание существующего кода**.

После распознавания реплики можно направлять в ограниченную очередь локального переводчика. Он получает английский текст, при необходимости соседние реплики для контекста, и возвращает русский текст с теми же временными границами. Модель EN→RU ещё предстоит выбрать и проверить на M1 Pro с 16 ГБ памяти.

Для этого понадобятся отдельный сервис перевода, идентификаторы реплик, обновление русской дорожки и общая отмена по поколению. Для режима «смотреть с готовым переводом» готовность интервала должна учитывать завершение **и ASR, и перевода**. Если перевод задержался или завершился ошибкой, интерфейс должен явно показывать состояние и позволять продолжить с оригиналом.

Перед расширением также полезно улучшить разбиение речи: сейчас окна фиксированные, без перекрытия и без переноса контекста Whisper между окнами. На границе окна фраза может обрываться. Это ограничение текущей минимальной реализации.
